Mendiolaza aprobó la apertura regulada de calle Azarero para conectar La Cercanía con El Talar

27/08/2026

El Concejo Deliberante de Mendiolaza aprobó la Ordenanza N.º 1168/2026, que autoriza la apertura regulada de calle Azarero para establecer una conexión vehicular entre el barrio cerrado La Cercanía y barrio El Talar.
